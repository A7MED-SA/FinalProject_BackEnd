# Quickstart: Reviews & Certificates

## Prerequisites

- Existing .NET 9.0 project with EF Core, Identity, JWT auth
- QuestPDF NuGet package: `dotnet add package QuestPDF`
- Existing EnrollmentService + ContentProgressService

## New Files to Create

| File | Purpose |
|------|---------|
| `Models/Review.cs` | Review entity |
| `Models/Certificate.cs` | Certificate entity |
| `Services/Interfaces/IReviewService.cs` | Review service interface |
| `Services/Interfaces/ICertificateService.cs` | Certificate service interface |
| `Services/Implementations/ReviewService.cs` | Review service |
| `Services/Implementations/CertificateService.cs` | Certificate service (+ PDF generation) |
| `DTOs/Review/ReviewDtos.cs` | Review DTOs |
| `DTOs/Certificate/CertificateDtos.cs` | Certificate DTOs |
| `Validators/Review/CreateReviewValidator.cs` | FluentValidation for review creation |
| `Controllers/ReviewsController.cs` | Review CRUD + flag endpoints |
| `Controllers/CertificatesController.cs` | Student certificate endpoints |
| `Controllers/AdminCertificatesController.cs` | Admin certificate endpoints |

## Files to Modify

| File | Change |
|------|--------|
| `Data/ApplicationDbContext.cs` | Add `DbSet<Review>`, `DbSet<Certificate>` + entity config |
| `Program.cs` | Register `IReviewService`, `ICertificateService` in DI |
| `Services/Implementations/ContentProgressService.cs` | Call `ICertificateService.GenerateCertificateAsync()` on completion |
| `Services/Implementations/RefundService.cs` | Call `ICertificateService.RevokeByEnrollmentAsync()` on refund |
| `specs/005-reviews-certificates/tasks.md` | Generated by `/speckit.tasks` |

## DI Registration (Program.cs)

```csharp
builder.Services.AddScoped<IReviewService, ReviewService>();
builder.Services.AddScoped<ICertificateService, CertificateService>();
```

## DbContext Configuration

```csharp
public DbSet<Review> Reviews => Set<Review>();
public DbSet<Certificate> Certificates => Set<Certificate>();
```

Add entity configurations:
- Review: unique index on `(UserId, CourseId)`
- Certificate: unique index on `Code`
- Both: use `ValueGeneratedNever()` for Guid IDs

## Certificate PDF Template

- Platform logo (top)
- "Certificate of Completion" (title)
- Student full name
- Course title
- Completion date
- Verification code + verification URL
- QuestPDF fluent API for layout
